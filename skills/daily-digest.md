# daily-digest: Morning/Evening Weather, News & System Brief

1. Call `get_weather_forecast()` for the current + 24h hourly and 7-day forecast.
2. Call `web_search_text("top world and tech news today")` (and `read_feed_readonly("hackernews")` if tech news is requested).
3. Call `get_system_headroom()` for a quick VRAM/disk check.
4. Format as a terse 3-section brief: Weather, Top Headlines, and System Headroom.
